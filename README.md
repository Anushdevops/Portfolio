# portfolio2
Run: `npm install && npm run dev` (open the printed URL). Build: `npm run build`; output in `dist/`.
Content: `src/data.ts`. Media: `public/hero.mp4`, `public/hero-poster.jpg`, `public/portrait.jpg`, `public/resume.pdf`.
Deploy: push to GitHub, import in Vercel/Netlify (build `npm run build`, output `dist`), or `npx vercel` / `npx netlify deploy --prod --dir=dist`.
